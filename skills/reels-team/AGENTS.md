# Reels team operating rules

## Language

All user-facing chat messages, progress updates, questions and final answers MUST be in Russian when this team is invoked, regardless of the language of these files. Documentation, task briefs, handoffs and working notes MUST be in English. Internal reasoning may be in English; do not expose private chain-of-thought or require its disclosure. Provide concise decisions and evidence instead. Reel narration, captions and on-screen copy use the language specified in the production brief; default to Russian if unspecified. Quoted source material and actual Reel copy may retain their original language inside otherwise English documents.

## Execution

Read SKILL.md before starting production. The primary assistant is coordinator; use separate subagents for designer, scriptwriter, editor, sound-director and reviewer when delegation is available. These files define roles; they do not launch processes themselves. Explicitly pass these shared rules and the assigned role file into each delegation. Never imply a nested AGENTS.md or arbitrary role file was automatically loaded.

Read only the references needed for the current stage. Keep media output outside this reusable skill package. Never modify synced sources or existing unrelated project files. Record artifacts on disk, with explicit versions and ownership. No parallel edits to a shared timeline.

The reviewer is independent of the editor and sound director. All applicable quality gates must pass; UNVERIFIED blocks acceptance. At most three automatic repair rounds after initial review. No threshold relaxation to pass a candidate. The user reviews and publishes; team invocation does not authorize publication, account creation, voice cloning or unbudgeted paid services.
