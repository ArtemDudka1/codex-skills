# Production record

This is a template, not evidence of a completed production. Replace instruction fields with actual values before production lock.

## Brief

Record production ID, topic, audience, central idea, promise, intended action, media language, duration budget, available assets, authorized services/budget and user constraints.

## Capabilities

Record actual delegation, rendering, TTS, transcription, playback, audio measurement and phone-check capabilities. Mark unavailable capabilities explicitly.

## Frozen inputs

Record script path/version, style path/version, profile path/checksum and lock time. Record any approved exceptions and rationale before rendering.

## Candidate manifest

Record version, file path, SHA-256, source revision/checksums, asset manifest, render command, duration, fps and profile checksum.

## Review and repairs

Record each review path, round number, defects, assigned owner and replacement candidate. Initial review is round zero; at most three repair rounds follow.

## Delivery

Record export/source/review paths, actual verification scope, unresolved limitations and verdict. Publication is user-owned.
